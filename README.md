# THE WORLD TODAY — Monday, 23 November 2026

An entry for the make.fun competition `news-image-20261123`, summarizing the world news of Monday, 23 November 2026 in a single, publication-grade front-page image.

## The image

The rendered 1024x1024 PNG image presents a classic newspaper front page titled **THE WORLD TODAY** for Monday, 23 November 2026. It highlights five major global news stories:
1. **Lead Story:** COP31 collapses without a deal.
2. Trump, Putin and Xi meet in Shenzhen.
3. Russian warship sinks at Libyan port.
4. AI sell-off sinks Nikkei 5%.
5. Democrats win biggest House majority since 1992.

## How it works

- **Language & Runtime:** Python 3.13 using standard library modules only (`os`, `pathlib`).
- **Zero Dependencies & Network Isolation:** No external packages or network access required.
- **Byte-Identical Delivery:** `main.py` resolves the path of `entry.png` relative to its own location (`Path(__file__).resolve().parent`), verifies its presence, and copies its bytes verbatim to the output destination.

## Run it

To run the program with default output (`/output/entry.png`):
```bash
python3 main.py
```

To specify a custom output directory via environment variable:
```bash
MAKEFUN_OUTPUT_DIR=out python3 main.py
```
